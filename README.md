# 算力集群配置模型 v2

选卡 → 填量 → 自动推演：机柜 · 机房面积 · 能耗与制冷 · 结构承重 · 网络配置 · 算力与显存规模，并可一键导出 PDF 报告。

## 文件

| 文件 | 说明 |
|---|---|
| `算力配置模型v2.html` | 主程序（UI + 算法 + 打印样式），零外部依赖，双击即可使用 |
| `chips.js` | 芯片参数库（唯一数据源）：47 款卡型 / 24 款服务器机型 / 5 档交换机 / 全部假设参数 |
| `算力配置模型.html` | v1 旧版，仅作对照保留 |
| `AI算力硬件速查表.html` | 芯片数据原始整理表（chips.js 卡型数据的主来源） |

> `chips.js` 必须与 HTML 同目录。双击 HTML 打开即自动加载；若浏览器阻止本地脚本，可点「导入配置」载入 JSON，或将目录用本地静态服务器打开。

## 使用

1. 顶部配置条：选业务场景（训练 / 推理 / 混部）→ 选加速卡 → 填数量 → 服务器机型与每机箱卡数自动带出 →「加入算力池」。
2. 微调假设：展开「高级假设」，所有参数（PUE、机柜功率上限、MFU、收敛比……）均可调，口径见第 08 节。
3. 「保存为方案」可存最多 4 套方案做横向对比（localStorage 持久化）。
4. 「导出 PDF」：在打印对话框中选择「存储为 PDF」。报告含口径与假设表、数据来源表，可追溯可复算。
5. 「导出配置 / 导入配置」：方案以 JSON 交换（含算力池与全部参数）。

## 维护芯片参数

直接编辑 `chips.js`（内容为标准 JSON，仅文件头带 `window.CHIP_DB = `）：

- `cards[]`：卡型。算力统一 **TFLOPS**（int8 记 TOPS 数值），显存带宽 **GB/s**，功耗 **W**。不确定的字段填 `null`（界面显示「—」，不会按 0 汇总）。`perfBasis` 必填（dense / sparse / mixed），`confidence` 标注数据等级。
- `nodes[]`：服务器机型。`card: "*"` 为通用机箱模板，可与任意卡型搭配；`rackDensity: null` 表示无厂商官方机柜密度数据，模型自动回退到功率 / U 位口径。`rackMode: true` 用于整机柜交付（如 NVL72）。
- `switches[]` / `defaults` / `paramMeta` / `presets`：交换机档位、默认假设、参数口径说明（驱动第 08 节自动生成）、出厂示例。

改完刷新页面即生效；也可以导出配置 JSON 做备份。

## 核心算法口径

| 项 | 口径 |
|---|---|
| 清单展开 | 机箱数 = 需求卡数 ÷ 每箱卡数（向上取整）；功率/机柜/承重/网络一律按**实配卡数**计算，报告并列显示「需求 vs 实配」 |
| 机柜数（三口径） | ①厂商官方机柜密度（默认取值口径，超出本机柜功率上限/U 位时自动下调并提示）②功率：Σ单机箱功率 ÷ 单机柜功率上限 ③U 位：ΣU ÷ 可用 U。无官方数据回退 ②与③取大；三值全部展示并标最紧约束 |
| 面积 | 主设备区 = 总柜数 × 单柜占地（含通道）；辅助区 = 主设备区 × 占比；另给机柜净占地校核与机房模块拆分 |
| 能耗（分层） | ①计算设备 ②网络设备 ③IT 小计 ④辅助负载 ⑤制冷显冷量（含围护附加与选型裕量）⑥制冷耗电（PUE 反推或 COP 正算，可切换）⑦设施总功耗（÷配电效率）⑧**市电容量需求**（×认购裕量）⑨**供电装机容量**（×冗余等级系数，与⑧分列）⑩年耗电量 |
| 承重 | 优先按机型标称重量累加；平均荷载 = 总荷载 ÷ 总面积（分摊值）；**单机柜局部荷载 = 最重机柜 ÷ 净占地，为结构控制值** |
| 算力 | 理论峰值 = Σ 单卡峰值 × 实配卡数（缺失精度跳过并标注，不按 0 计）；有效算力 = 主精度峰值 × MFU（训练 45% / 推理 35% / 混部 40%，可调）；主精度按 bf16→fp16→fp8→int8 回退链取值（国产卡未公开 BF16 时自动回退） |
| 显存与模型规模 | 显存容量/带宽按卡数加总；可训练参数 = 可用显存 ÷ 16 B/参数；可推理参数 = 总显存 ×(1−KV 预留) ÷ 2 B/参数 |
| 网络 | 训练端口 = Σ网口 × 平面数；每叶下联 = 端口数 × 超分比/(超分比+1)；叶 = 端口 ÷ 下联；脊 = 叶 × 上联 ÷ 单台端口数；BOM 含铜缆/光纤链路、光模块、光纤芯数与网络设备功耗 |

## 数据校验 fixture

默认示例：H100 SXM × 512（8 卡/箱，风冷，机柜 12 kW，PUE 1.25，MFU 45%）

| 指标 | 模型输出 | 手算 |
|---|---|---|
| 机箱数 | 64 台（7.23 kW/台，含电源效率 0.94） | (700×8+1200)/0.94 = 7.23 kW |
| 机柜（厂商/功率/U 位） | **64** / 39 / 10，取厂商口径 | ceil(64/1) / ceil(463/12) / ceil(384/40) |
| 总柜数 | 75（计算 64 + 网络 10 + 边界 1） | 网络柜取 max(64/10, 58 台交换机/6) |
| 机房面积 | 253.1 m²（主设备区 187.5 + 辅助 35%） | 75×2.5×1.35 |
| bf16 峰值 / 有效 | 506.57 / 227.96 PFLOPS | 989.4×512、×0.45 |
| 显存 / 带宽 | 40.96 TB / 1.72 PB/s | 80×512、3350×512 |
| 市电需求 / 2N 装机 | 796 / 1,592 kW | 分层链路逐项核对（见第 03 节） |
| 局部荷载 | 4.6 kN/m²（< 12，满足） | (85+250) kg ÷ 0.72 m² × 9.81 |

## 数据来源与免责

- 卡型数据主源为 `AI算力硬件速查表.html`（45 款），单位归一化后录入；NVIDIA/AMD 主流型号的 fp16/fp8/tf32/fp32/fp64 已按官方 datasheet **稠密值**覆盖修正（速查表 f8 列疑似与 f16 同值，旧版模型的 H100 fp16=1513 亦为错误口径，均已修正）。
- 服务器机型数据源自 v1 的机型库，已修正：重复的 `HGX8_910B4`、`AI8_310` 卡型错配、910C 的 U 高矛盾；国产无现成机型者提供通用机箱模板。
- 所有参数整理自公开规格，**正式选型、采购与施工图设计必须以厂商最新 datasheet 及书面确认为准**；本模型用于方案前期估算与比选。
